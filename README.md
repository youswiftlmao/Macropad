# Macropad

A custom 3-key macropad using a Seeed Studio XIAO RP2040 microcontroller.

## Features
- 3 programmable keys
- Custom-designed PCB using KiCad
- Custom 3D-printed enclosure designed in Fusion 360
- RP2040-based firmware


## Repository Structure
- `cad/` — CAD source files and 3D assembly exports
- `pcb/` — schematic, PCB layout and manufacturing files
- `firmware/` — macropad firmware
- `images/` — project images, renders and wiring diagram
- `BOM.csv` — bill of materials
